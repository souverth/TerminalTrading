# Security Policy

Terminal Trading is used inside trading products, so we treat security reports as a priority.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository (Security tab, "Report a vulnerability") with a description of the issue, the affected
package and version, and steps to reproduce. Please do not open a public GitHub
issue for anything you believe is a vulnerability.

You will get an acknowledgement within two business days and a fix or a
mitigation plan within a timeframe that matches the severity. We credit
reporters in the release notes unless you ask us not to.

## Supported versions

Security fixes land on the latest published minor of `terminal-trading`. Commercial
licensees are covered by the Support & SLA Schedule at
https://www.luxalgo.com/licensing/#sla, which lists supported versions and
response targets by tier.

## Scope

- `terminal-trading` (this repository) and its published builds on npm.
- The attribution mark, providers and workspace shipped in this package.

Vulnerabilities in PineTS or Terminal Trading PineTS belong in their own repositories.
